# C012 creation inputs (Win32 x64)

Static observations of `ffxiv_dx11.exe`, SHA-256 `52042b60631cf2c48851b3aaee36e9ec4fedd6d7f2c68f0e9a8c3befb0af9f98`, using REA `execute-rizin-command` / Rizin 0.9.1. No running-client or screenshot comparison.

- **Identity:** descriptor `0x1428d4ca0` points to `"C012"` and factory `0x1418c3ce0`. Row `+0x20` is 9. The factory requests `0x188` bytes; constructor `0x141912860` installs vtable `0x142325580`. The type-9 path at `0x1419136d9` resolves the AVFX path at payload `+0x0c`; `0x141913832` passes that payload to `0x141c2ff60`. Evidence: `ev_62d2172066c4b0edbaa4d9da6960d4dedf594e0d6274c3f09cd33fa0c04d02aa`, `ev_dba66ba85802d88aed3aa7a6de6ec8daab2cf9477b3ce2feedab5d68cc468521`.
- **TRS:** the command body checks the counts at `+0x1c/+0x24/+0x2c` for nonzero, and reads three floats via signed payload-relative offsets `+0x18/+0x20/+0x28`. It seeds an affine matrix with diagonal scale (ones if absent). `0x140796970` builds X rotation from half-angle sine/cosine, then calls `0x14076b040` and `0x14076b110`. Their four component updates are left multiplication by Y then Z. `0x14033b2a0` rotates the scaled basis columns; `0x141c30336` adds the position after rotation. Thus, for column vectors, the command matrix is `T · Rz · Ry · Rx · S`. `0x141c3038b..39f` copies the four columns into a creation packet; the success branch passes this packet to `0x14045d410` separately from external binding selectors. Evidence: creation record above, `ev_7c5da535242ea6054f827fdaec79b65890695d9de5aefdbfbe2f5d982948f354`. The renderer uses ordinary f32 trig, not a bit-exact emulation of the client CRT. The TMB decoder accepts the evidenced 3/3/3/4 layouts.
- **Placement boundary:** the packet matrix is not evidence that every binder uses `caster_world * command_matrix`. The selector branches and controller placement also have independent inputs. The renderer applies the decoded TRS directly for an identity host; default TRS retains existing preview placement. Nondefault TRS on a nonidentity host still uses the per-occurrence resolved frame override. A binder can supply its own position: the translated row below does not acquire an extra post-sample offset.
- **Flags:** masks `1`, `2` and `4` are independent controller operations, not visibility bits. See the ownership and eligibility trace below. Evidence: `ev_3edddd2299365fad0f3565a9666489d216bb364af045f8fe337d435311338d3c`, `ev_da3c3f62a5139379f35eda0094962f5203698f1ac26380c512b66debcf786fea`.
- **RGBA:** `0x141c300e1` tests count `+0x34`, reads four floats via offset `+0x30`, and calls `0x14045d890`, storing them as R/G/B/A at controller `+0x260..26c`. `0x14045d5d8` forwards them to `0x1403907a0`; a valid live handle forwards to `0x14037ade0`. For a live Document, `0x1403b4fd0` multiplies the three input channels by definition floats `+0xb8/+0xbc/+0xc0` and writes `Document[+0x228]+0x30..38`; alpha is copied to `+0x3c`. The AVFX reader assigns those definition offsets from `RvR/G/B` at `0x1403adc9e`, `0x1403adcac`, `0x1403adbc2`. Evidence: `ev_eb7ecfa2982b580e16613cd49b8fdb546614853bac350fb83bdf602325df5e3d` and flags record above.

## Document color at draw time

The two submission paths at `0x1403b9be4` and `0x1403ba370` load the entire 16 bytes at `[Document+0x228]+0x30`, copy to the stack, and pass the address in RDX to `0x140382f80`. That routine saves RDX in RSI, maps the `+0x418` buffer, and copies `[rsi+0,4,8,c]` unchanged to buffer offsets `0x20..0x2c` (`0x1403833f3..3440`). `0x1403834be` selects the binding via `+0x410`; `0x140384e81..4eb7` resolves `g_PS_DocumentParameters` and creates its 80-byte buffer. Thus RGBA is float4 **element 2** in a named PS constant buffer, separate from the particle vertex colors. REA/Rizin: `ev_dc8035500986d7437b20baaca72525a60316c5485d1f472deb867b5028f4150b`.

In the installed Apricot DXBCs, resolve the register by RDEF name (it varies). Shape PS8 multiplies sampled color by vertex color, then by `cb1[2]` (SHEX word 98). Model PS26 does the latter at word 245 (`cb2[2]`) after Fresnel, texture and vertex color. LightModel PS1 does so at 215; Powder PS1 at 108, **after** its texture lower clamp. Decal / DecalRing PS1 also multiply at 281 / 516. In each of the Shape, Powder, Model, LightModel, Decal, DecalRing and two GBuffer decal packages, a scan of pixel-program instructions found a `MUL` reading element 2, either as RGBA or as separate RGB and alpha. This does not establish every variant's full material equation.

Action playback preserves parsed revised RGB (missing tags default to one; explicit zeros remain zero) and gives the staged and fallback samplers identity revised RGB. This prevents `VfxRuntime::revised_color` from baking the factor into inherited or quantized particle colors. The compositor supplies `(RvRGB × command.rgb, command.a)` per occurrence in input order; the batch keys the float bits alongside material state **before** sorting. The common fragment path consumes it after particle color, texture and Fresnel, before alpha rejection and blend control. Line endpoints, Polyline edge colors and Disc's vertex-stage milli-unit packing remain independent.

`effects/tests/document_color.rs` compares actual `EffectPlayer` GPU frames with two simultaneous Stone hand effects sharing one AVFX. It isolates each occurrence by alpha, checks intermediate alpha against both endpoints, and compares HDR-range RGB command inputs against an equivalent controlled edit of the AVFX root revised color (including all zero). `effects/tests/particle_tone.rs` checks linear HDR values for Disc, Quad and LightModel; the Disc's red `12` clamps to `10` before a `0.5` Document factor gives `5`. These are controlled renderer checks, not live-client frame comparisons.

## Real resources

### C012 command ownership and release

- **1 — allocate separately.** `141913680` uses the embedded `this+0xa8` constructor when clear. When set, `141c00bd0` allocates **a fresh 0xf0-byte node per call**, initializes the same base, and appends it to the manager's doubly linked list (`+0xd8/+0xe0`, pending-release byte `+0xe8=0`). Allocation failure returns null; `141912ba2` aborts that prepare attempt. Two overlapping commands referencing the same AVFX do not share a controller.
- **2 — bypass one eligibility predicate.** At `141913117`, absent mask 2 the branch rejects if the resolved call `14090da00` returned false **and** context DWORD `+0x178 != 0xc6`. Missing preceding optional providers can jump directly to `14191314a`; they are not a failed eligibility result. This check belongs to the creation branch, not all subsequent frames.
- **4 — conditional early termination.** At `141912e9e`, object virtual `+0xe8` must return an unsigned ordinal `<=0x332`. The object table slot, `14089ae90` result, and its virtual `+0x270` result must exist. `1408a5ce0(state,0x20)` reads bit 0 at `state+0x3cc` (state ID 32). On true the command calls `141c30940(controller,0,1)` and sets `r15b`; this diverts flow to `14191343c`, not back to creation. At nonnegative command age it calls command virtual `+0x138(true)`; this C012 vtable resolves to `1419013e0`, which updates command/parent flags. Lookup failure and clear state continue normal checks. This does not invert the meaning of mask 2 and does not continuously hide/show an existing packet.
- **Cleanup versus lifetime.** `1419138b0` stops/destructs the embedded controller chain. For external controllers it calls `141c30940(head,0,1)` if present, sets external `+0xe8=1`, clears **both** command pointers `+0xa0/+0x98`, and returns without freeing the node. At manager update `141c00a40`, marked nodes are unlinked/freed when inactive or when the completion helper `141c308c0` returns true. That helper checks controller flags, failure state and the validity of the underlying handle. The manager also has an overflow pass when more than `0x400` nodes were visited; the preview is bounded to 1,024 command occurrences per loaded scene and does not emulate competing allocations from unrelated game scenes.
- **What `(0,1)` does.** With controller bit `+0x10 & 0x10` active, `141c30940` forwards to `14045d450` → `140390590`. After handle/generation checks the latter records last request `1` and sets **bit 1** of the pending mask (`14039066c..684`). The framework consumes the bit and passes `1-1` to `1403bd390` through Document `+0x210` (`1403b6263..6341`); `+0x210` is the first attached child, set on empty-list append at `1403b1048`. `1403bd390` reads a signed Timeline index from the Scheduler trigger table and attaches that Timeline when valid. This is not an unconditional global kill or a hard-coded fade. Early stop and external cleanup can write the same bit on the same boundary; the bitmask coalesces the request.

## Stone: the directional goal query

`mgc_ston1t0h.avfx` (SHA-256 `aea4162c14fb5aebe72422139f3cda4830a6e25ec8782dadd2c003a511956b92`) has one Linear binder at 22100. Start `(BPT=0, BPTP=3, BPID=16)` queries the caster's ElementId 16. Goal `(BPT=1, BPTP=2, BPID=0)` selects the target list, then **a directional target query**, not ElementId 0. The file's `BPTP` tag is what some earlier notes call “BTPT.”

1. **Dispatch/identity:** `0x1403c00e4` calls listener slot `+0x28` with the list ordinal, then `+0x38` with the output pointer, `(properties[0x26] >> 3) & 7`, `properties[0x27]`, and the selected entry. The action controller installs vtable `0x14216be20` at its `+0x90`; here slot `+0x28` returns the ordinal and `+0x38` is `0x14038e1b0`. For mode 0, it resolves `listener+0x60+4*ordinal` in the object table and checks the saved identity at `+0x130+8*ordinal`; missing/mismatched objects return false. Mode 1 uses the corresponding object wrapper. `0x14038c760` first tries a per-target C012 point override if its signed word is not `-1`; Stone's second selector is `-1`. In `0x14038c800`, type 2 jumps to `0x14038cdb0`, passing the target object. **BPID 0 is not used as an ID in that branch.** This is not the unrelated simple Character listener at `0x140430a60` (whose list-query slot returns false).
2. **Inputs:** the helper resolves the *caster* from the listener (`+0x58`, including the cached identity for mode 0). It computes the vector from the selected target's position to the caster position. Position selection can use the active draw object at `+0x100`/position `+0x50`, the position getter `0x1408989b0`, or the caster wrapper getter in mode 1. Above distance `0.05`, it adds that vector to the target position getter and submits the resulting world-space reference point to target virtual **`+0x1a8(out_matrix, reference_point, true)`**. If caster/direction is unavailable or too short, the alternative reference uses target yaw (`+0xc0`) and the constant vector `(0,0,1000)` instead.
3. **External provider:** base slot `0x14089cee0` can call the current draw object's `+0xa0(out,0x3d,reference,true)`, use a separate scene object at `+0x108` (including a `0x2e` point/position and a direction flattened in Y), or emit identity basis at target position on the no-provider path. A derived implementation at `0x140907a90` may select a related draw object and a runtime-selected point before delegating to the base. Thus the static PAP/MDL and a target origin alone cannot determine which 4×4 the client returned. This is a scene-object callback; the trace does **not** establish a universal physics raycast. Missing object-table entry and wrapper fallback are distinct from a successful callback.
4. **Result:** `0x14038da70` calls `0x14033a240` with listener matrix at `+0x10` and the provider's output, then writes three basis columns and translation, homogeneous lanes `0,0,0,1`, returning success. In column convention the result is `provider * listener`. Goal success enters the shared binder reducer at `0x1403c018b`; failure branches out before reduction. Controlled check: provider Y+90°, translation `(1,2,3)` and listener diagonal `(2,3,4)`, translation `(5,6,7)` yield columns `(0,0,-2),(0,3,0),(4,0,0)` and position `(8,8,-2)` (binary32 scalar operations lifted from the original multiply). This checks composition and packing, **not** the result of a live game query.

REA records for these paths: `ev_def12a4ce8c2eee1bbecb195742f894ef2fce5ccdd623aa73a54c0197e893abc` (ordinal/dispatch), `ev_9b4618351f366d3b1289ccad4086e4a863ef0233b8fcbbf5968649d94a00036f` (direction/reference constants), `ev_12710045517a25afa431450771cae62a40e5dd1a7e8a6881aa2d9a5e9f252dc5` (target implementations), `ev_cd1552e3991153dd6892f7c1805b842c02c8c2471b671f76cb6354023f7fd394` (controller table and final affine).

**Renderer boundary:** supply the final query result, keyed by C012 occurrence, Linear binder index 0 and target ordinal 0. `directional_goal.rs` passes finite affine columns (including shear) without TRS decomposition. In the playback copy only, the Linear goal reads a private matrix slot through the pinned player's type-3 getter, which feeds the same reducer as the object getter. The slot is not looked up on any game model. `{missing:true}` leaves the slot empty to represent an observed query failure; omitting the provider entirely leaves the original AVFX on fallback. Target ordinals, caster ElementIds, authored COF curve and deadlines remain original. On the real Stone resource, a failed birth produces no projectile; a failed refresh after birth retains the last successful frame. These are renderer differentials, not live-client observations.
